# Accessibilité - Natacha V2

Le projet **Natacha V2** vise à offrir un assistant vocal accessible et autonome[cite: 1, 2].

## Fonctionnalités d'accessibilité

* **Commande vocale mains libres** : Utilisation du projet sans clavier ni écran via l'interface audio[cite: 1, 2].
* **Retours sonores** : Synthèse vocale naturelle (XTTS v2) pour toutes les réponses et confirmations[cite: 1, 2].
* **Interface Web (Dashboard)** : Conçue pour être lisible avec des contrastes élevés[cite: 1].

## Signaler un problème d'accessibilité

Si vous rencontrez un obstacle d'utilisation, vous pouvez ouvrir une *Issue* sur le dépôt en précisant le nœud concerné[cite: 1].
