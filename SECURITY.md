# Politique de Sécurité - Natacha V2

## Versions prises en charge

| Version | Prise en charge | Notes |
| ------- | ---------------- | ----- |
| 2.0.0   | :white_check_mark: | Version actuelle sécurisée |
| < 2.0.0 | :x: | Non maintenue |

## Signaler une vulnérabilité

Si vous identifiez une faille de sécurité :
1. Ne créez pas d'issue publique.
2. Contactez directement le propriétaire du dépôt.
3. Un correctif sera déployé sur la branche `main`.
